# Historical releases

The original application ZIPs for Platform 0.1.0 through 0.2.3 were preserved,
but their exact source trees were not. Each is published as a separate
historical binary-only GitHub release so early builds remain available without
misrepresenting current source as historical source.

All timestamps are the original local archive modification time in British
Summer Time. SHA-256 values identify the preserved files exactly.

## Source-retention notice

Every release above carries this notice:

> Historical binary-only snapshot. The exact source tree for this version was
> not retained; the generated source archive contains only the historical
> manifest and licence.

The legacy version tags intentionally point to one metadata-only archival
commit containing this manifest and the MIT licence. Version 0.2.4 is the first
tag that points to the complete retained source tree.
